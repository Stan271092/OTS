## Предыдущая итерация v4 — цельная смола

Пользователь сравнил прежний реалистичный статичный рендер с новой сферической WebGL-сценой. Согласовал предложение вернуть слитную форму исходного Blender-объекта, сначала настроить неподвижный материал, затем оживить его. Не PNG-анимация.

- Перед правками создан бэкап `D:/AI/ORCA PROJECTS/OTR/Back up files/OTS before resin v4 2026-09-11 03-56-48`.

# Design: клиентские каталоги продукции OTS 2026

## Цель

Создать из книги `Каталог продукции_2026 — v2.xlsx` два самостоятельных клиентских PDF-каталога:

- `Каталог продукции 2026 — RU.pdf`
- `Product Catalogue 2026 — EN.pdf`

По отдельному одобрению пользователя в исходной книге исправлены только шесть ячеек «Компаунды RU»: AB7=4.2, AB8=4.1, AB16=4.3, AB17=3.8, AB18=4.4, AB22=4.1. Значения взяты из английского листа. Сайт не изменяется. Созданы две отдельные XLSX-книги с тремя языковыми листами каждая.

## Состав

Каждый PDF содержит все три языковых листа своей версии:

1. Компаунды / Compounds
2. Эпоксидные смолы / Epoxy resins
3. Отвердители / Hardeners

В PDF не переносятся пустые служебные строки и пустые хвостовые колонки Excel. Содержательные данные, значения, единицы измерения, символы и переносы текста сохраняются.

## Визуальная система

- Белый фон и спокойная корпоративная сине-голубая палитра OTS.
- Титульная страница с логотипом OTS, названием каталога и годом; без контактных данных.
- Для каждого раздела — отдельная синяя разделительная страница с названием раздела.
- Основной текст — нейтральный системный sans-serif; заголовки — с усиленным весом и синим акцентом.
- Таблицы: тёмно-синяя шапка, тонкие голубые линии, чередование очень светлых строк, удобные внутренние отступы.
- Нижний колонтитул: название каталога, название текущего раздела и номер страницы.

## Разметка таблиц

- По уточнению пользователя таблицы сохраняют исходную структуру Excel, без тематического разбиения и дополнительных ID.
- Компаунды: все 29 колонок B:AD, порядок строк и объединённая многоуровневая шапка. Формат A2 альбомный; продолжение только по строкам (RU — 3 страницы, EN — 2).
- Смолы: три исходные таблицы, каждая целиком на A3 альбомном, включая объединения рекомендаций.
- Отвердители: исходная таблица A:G на A4 альбомном.
- При вертикальном продолжении повторяется полная шапка.
- Ячейки с переносами строк сохраняют переносы в PDF.
- Строка таблицы не разрывается между страницами, насколько это позволяет содержимое.

## Технология

Python/openpyxl извлекает данные из исправленной книги; ReportLab формирует PDF напрямую, со встроенными шрифтами Arial и векторными логотипами из `new logo RU.svg` / `new logo eng.svg`. PyMuPDF проверяет извлечённый текст каждого исходного значения и границы текста, рендерит все страницы для визуального контроля. Объединённые рекомендации повторяются для каждой относящейся к ним марки.

Итоговая папка: `Клиентские каталоги 2026/`. PDF: `Каталог_продукции_2026.pdf` (11 страниц), `Product_Catalogue_2026.pdf` (10 страниц). Встроены закладки трёх разделов. Скрипт сборки сохранён в `docs/build_client_catalog_pdfs.py`.

## Проверки

Перед выдачей:

- проверить существование и размер обоих PDF;
- открыть PDF повторно через `pypdf`, проверить читаемый текст, порядок разделов и наличие русской/английской версии без смешения языков;
- проверить отсутствие пустых страниц и обрезанных ключевых заголовков;
- отрендерить первые страницы и выборочные страницы таблиц в изображения для визуального контроля;
- открыть итоговые PDF после всех проверок.

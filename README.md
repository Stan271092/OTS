# OTS — сайт-визитка

Локальная рабочая копия светлой дизайн-концепции OTS. Обычные HTML, CSS и JavaScript: без фреймворка, npm и сборки. Название папки не означает публикацию на GitHub.

## Запуск

Нужен Python 3. Откройте терминал в этой папке и выполните:

```sh
python serve.py --port 8767
```

Откройте <http://127.0.0.1:8767/>. Остановка — `Ctrl+C`. Сервер слушает только `127.0.0.1`, отдаёт локальные файлы и не обрабатывает отправку форм. Не используйте его как публичный сервер.

## Структура

- `index.html`, `styles.css`, `app.js` — сайт в корне.
- `hero.css`, `sections.css` — светлый бело-синий стиль с точечным глассморфизмом поверх `styles.css`; охватывают все разделы сайта.
- `embed-host.js` — лениво загружает `webgl/v4/embed.html`, который подключает `scene.mjs`; управляет жизненным циклом (пауза при скрытии родительского CSS, вкладки, выходе за экран), ручная пауза сохраняется; postMessage с проверкой same-origin/source/payload.
- `check_site.cjs` — браузерная проверка главного сайта с iframe: запускает модель внутри родительского сайта, проверяет движение по пикселям и draw counter. 8 ширин, 4 отрасли, форма/меню/фокус. Один временный Edge, нужен локальный сервер 8767.
- `assets/` — локальные шрифты, фотографии и SVG-иллюстрации.
- `serve.py` — локальный сервер, в том числе для ES-модулей.
- `PROJECT-STATE.md` — согласованное направление и состояние работы.
- `./webgl/` — рабочий прототип настоящего 3D: <http://127.0.0.1:8767/webgl/>. Перетаскивание мышью, стрелки и Home, фон, качество, пауза. Вкладка и объект вне экрана автоматически приостанавливаются.
- В центре крупная прозрачная гелевая капсула с мягкой деформацией, вокруг 8 прозрачных и 9 чёрных капель. Внутри четыре порошковых сгустка: 1320 зёрен в бережном режиме, 2160 в подробном. Малые сферы уменьшены на 15% относительно второй версии. По центральной массе и прозрачным каплям проходят широкие медленные волны. Максимум 24 кадра/с в обоих режимах, MSAA-сглаживание и разрешение не ниже нативного. Траектории художественные, без гидродинамической симуляции.

Все ресурсы сайта используют относительные пути. Hero содержит `iframe` с `webgl/v4/embed.html`; `embed-host.js` лениво загружает сцену и управляет паузой.

## Ограничения

- Форма только проверяет поля в браузере: ничего не отправляет и не сохраняет. Не вводите конфиденциальные данные.
- Логотип предоставлен пользователем (`assets/ots-logo.svg`); отраслевые фотографии — иллюстрации, не подтверждённые кейсы OTS.
- До возможной публикации нужно согласовать тексты и контакты, проверить права на фотографии и шрифты, подготовить обработку персональных данных при подключении настоящей формы.
- Нет CMS, аналитики и серверного приложения. Исходные Blender-файлы, генераторы, старые рендеры и резервные копии не перенесены.
- WebGL — демонстрация движения, не утверждённый финальный материал. Прозрачность приближённая; HTML позади объекта не преломляется. Визуальную близость к густой смоле ещё нужно согласовать.

## Новый образец цельной смолы (v4)

Откройте <http://127.0.0.1:8767/webgl/v4/>. Предыдущая сцена `/webgl/` оставлена без изменений для сравнения.

V4 использует сохранённую замкнутую геометрию слитного Blender-объекта, три малые прозрачные капли, одну крупную переднюю и семь чёрных включений (сокращено с двенадцати по запросу пользователя). Камера зафиксирована; вращение мышью и клавишами отключено. При открытии автоматически работают локальная GPU-деформация, движение капель перед смолой/за ней и дрейф порошка. Кнопка «Пауза» останавливает движение. При prefers-reduced-motion анимация не запускается.

Зазоры проверяются в 3D, не в экранной проекции: перекрытия разрешены. Общая компактная наклонная эллиптическая траектория удерживает десять малых сфер рядом; каждая проходит спереди и сзади. Их средняя угловая скорость общая, у чёрных есть дополнительная ограниченная модуляция движения. Крупная капля радиуса .6 держится спереди и медленно дрейфует в пределах .05. Матовый порошок рисуется после основной смолы, но до передних прозрачных капель, чтобы они его преломляли; per-grain depth отключён. Это художественное приближение, не физическое рассеяние внутри смолы. Точность воспроизведения Blender пока не утверждена.

Светлый/тёмный фон теперь входит в линейный расчёт прозрачного материала; финал кодируется в sRGB один раз. Поэтому в этих режимах canvas рисует известный фон, а не имеет прозрачную подложку. Режим «Прозрачный» сохраняет alpha/ACES fallback, без преломления HTML. Деформация состоит из последовательных сдвигов, сохраняющих объём; это кинематическое перетекание, не расчёт гидродинамики.

В последней настройке одна чёрная сфера увеличена на 22%, одна прозрачная на 20%; движение замедлено примерно на четверть, высоты разнесены. Локальные волны стали заметнее, отражательный контур ослаблен. В каждом порошковом облаке есть мелкая взвесь и более крупные матовые крошки. Чёрные полосы передних сфер устранены исключением переднего цвета из источника преломления, с GPU-регрессией on/off.

Передняя/задняя поверхности дают оценку толщины вместо сферической хорды. Это экранное преломление, а не трассировка лучей; невидимые поверхности, многократные отражения и сложные пересечения не решены физически точно. Порошок: 3000/4600 мелких зёрен. Максимум 20 кадров/с; пиксельный бюджет 0.8/1.6 Мп, автоматическая пауза. Пиковая память и нагрузка зависят от видеокарты; бережный режим не означает нулевую нагрузку.

`webgl/v4/reference.png` — предоставленный пользователем статичный эталон, только для сравнения ниже сцены; не подложка 3D и не публичный ассет с проверенными правами.

```sh
node --test webgl/v4/test-layout.mjs webgl/v4/test-resin.mjs webgl/v4/test-optics.mjs
node webgl/v4/check_webgl.cjs
```

## Проверки 3D

```sh
node --test webgl/test-gel.mjs
node webgl/check_webgl.cjs
```

Последняя команда требует Windows, Node.js с глобальным WebSocket, Python и Microsoft Edge по стандартному пути. Она поднимает временный сервер на 127.0.0.1:8768 и один headless-браузер; после проверки закрывает оба. Скриншоты сохраняются в `webgl/checks/` (исключены из Git). Зависимости не устанавливаются. Three.js включён локально, его лицензия — `webgl/vendor/THREE-LICENSE.txt`.

## Git

Репозиторий инициализирован локально с начальной веткой `main`; текущая рабочая ветка — `feat/webgl-hero`. Коммитов и remote нет, файлы не добавлены в индекс. Создание удалённого репозитория, коммиты, push и публикация — только по отдельному запросу пользователя.
